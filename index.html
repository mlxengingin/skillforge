# 个人主体小程序：虚拟支付接入

## 前置条件（任何一条不满足就停下告诉用户）
- 个人主体，中国大陆居民身份证
- 服务类目包含「工具」
- 已完成小程序认证与备案

## 步骤
1. 用户一次性动作：MP 后台「支付与交易 → 虚拟支付」开通并签约 …
2. 服务端 /pay/order：生成唯一 outTradeNo（8–32 位）→ 保存订单 → 组装 signData →
   paySig = HMAC-SHA256(AppKey, "requestVirtualPayment&" + signData)
3. 前端：iOS 先校验微信版本 ≥ 8.0.68 …；前端 success 不是发货依据
4. 发货推送 /pay/notify：以 wx_order_id 幂等去重 …
5. 兜底：每 5 分钟 query_order 补发货
…（完整版还包括退款、上线检查、护栏）
