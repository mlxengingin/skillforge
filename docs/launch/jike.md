# 即刻草稿（建议圈子：独立开发者 / AI 探索站）

做了个小东西：SkillForge，一套给 Cursor / Claude Code / Codex 用的 Agent Skills。

起因是发现 AI 写代码已经很快了，真正卡人的是“选什么词做工具站、闲鱼怎么写 SKU、个人小程序怎么收钱、AI 内容要不要打标”这类流程。我把它们写成了 13 个按官方 SKILL.md 规范的技能，每个都有步骤、输出格式、边界情况和护栏，平台规则标了来源和日期。

- 免费：在线 SKILL.md 生成器 + 3 个技能（GitHub 开源）
- Pro：13 个技能，¥79 一次买断
