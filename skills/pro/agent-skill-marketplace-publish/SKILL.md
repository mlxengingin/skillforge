# Agent Skill Marketplace Publish

## When to use
Ready to sell a skill pack on agent marketplaces.

## Workflow
1. Zip folder with SKILL.md (+ assets); no secrets.
2. Write listing: who / job / sample output / install steps.
3. Price: $5–$15 single-purpose; $20–$49 deep domain packs.
4. Submit Agensi security scan; keep RuleSell / HireAISkill mirrors.
5. Add 3 demo prompts buyers can paste on day one.

## Guardrails
- Do not scrape others skills.
- Disclose AI-assisted authorship where required.
- Keep 70% creator share math honest (platform fees vary).
