# Prompt to Listing

## When to use
Need sales page copy for a skill pack or micro-tool.

## Workflow
1. State buyer role + painful job + time saved.
2. Write hero, 3 benefit bullets, what is included, what is not.
3. Add install/use steps under 5 minutes.
4. Add FAQ: refund, updates, supported agents.
5. Add 2 demo prompts.

## Guardrails
- No fake testimonials.
- No guaranteed income language.
