# 闲鱼 AI 服务上架

## When to use
Need first cash this week via AI automation / PPT / agent setup services.

## Workflow
1. Pick 2 SKUs (example: 自动化日报搭建 / 落地页48小时).
2. Write title, bullets, sample screenshots checklist, delivery time.
3. Define revision policy and what is out of scope.
4. Prepare remote delivery SOP (inputs needed, acceptance criteria).
5. Log each buyer pain → candidate product features.

## Guardrails
- No fake social proof.
- No claims of guaranteed monthly income.
- Clarify client data / machine access responsibility.
