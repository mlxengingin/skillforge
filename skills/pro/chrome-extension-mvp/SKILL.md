# Chrome Extension MVP

## When to use
Daily personal workflow pain solvable in the browser.

## Workflow
1. Write one-sentence job and non-goals.
2. Manifest V3 scaffold: popup + content script only if needed.
3. Local install test checklist.
4. Store listing: title, short/long description, 3 screenshots plan.
5. Pricing: buyout first (CNY 19–49) before subscription.

## Guardrails
- Minimal permissions.
- No silent remote code execution.
